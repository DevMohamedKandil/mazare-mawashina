# مزارع مواشينا | Mawashina Farms

واجهة عربية RTL لإدارة المزرعة، متابعة الثروة الحيوانية، المساهمين، دراسة جدوى تسمين الخرفان، ودليل المساهمة ومرحلة بيع اللحوم والطلبات.

## التشغيل
افتح `index.html` باستخدام Chrome أو Edge. لا يحتاج النموذج الأولي إلى تثبيت حزم.

## إعدادات نموذج الدراسة
- 5 مساهمين افتراضياً.
- قيمة المساهمة 50,000 جنيه.
- رأس مال مستهدف 250,000 جنيه.
- 15 خروفاً لمدة تقديرية 120 يوماً.
- أرقام الدراسة افتراضات قابلة للتعديل وليست أسعاراً مؤكدة أو عائداً مضموناً.

## المرحلة التجارية التالية
شاشة تخطيطية لبيع اللحوم بعد الذبح في مجزر مرخص، مع كتالوج منتجات، مناطق توصيل، مراحل الطلب، وحساب ربحية الذبيحة. لا تتضمن حالياً بوابة دفع أو تنفيذ طلبات حقيقياً.

## حدود الإصدار
البيانات محلية في المتصفح (IndexedDB)، ولا توجد مزامنة سحابية أو Backend/SQL Server متعدد المستخدمين بعد. يلزم اعتماد التراخيص والاشتراطات البيطرية وسلامة الغذاء قبل بدء النشاط التجاري.
